# Notchset: rules for AI agents

Notchset items are installed in this project as source files you own:

- Notchset components: `components/ui/notchset/`, blocks in `components/ui/notchset/blocks/`, shared helpers in `lib/notchset/`. The foundation's CSS is merged into the global stylesheet by the shadcn CLI. Each one's guide is served, not installed: `https://notchset.dev/md/<id>.md`. Read it before using or editing the component.

## Rules
1. Prefer a Notchset component over writing a new one for the same job. If it isn't installed yet, install it (routing table below) instead of recreating it.
2. Pass content, data and callbacks through props. Components never fetch data themselves.
3. Colours: components read the app's shadcn tokens through the foundation's roles. Don't add Tailwind colour classes inside Notchset components; put overrides in the app's own CSS or tokens.
4. Dark mode follows the `.dark` class or `data-theme="dark"` on an ancestor. Motion is built in: reduced motion, or data-motion="reduced" on the root, turns moves into fades. Don't wrap Notchset components in other animation libraries.
5. Keep every ARIA attribute, keyboard handler, focus rule and `data-slot` attribute listed in the component's guide.

## Installing more

The project's `components.json` needs both registries:

```json
{
  "registries": {
    "@notchset": "https://notchset.dev/r/{style}/{name}.json",
    "@notchset-pro": {
      "url": "https://notchset.dev/r/pro/{style}/{name}.json",
      "headers": { "Authorization": "Bearer ${NOTCHSET_TOKEN}" }
    }
  }
}
```

Pro items need `NOTCHSET_TOKEN` in `.env.local`. If an install returns 401 or 403, tell the user plainly and link https://notchset.dev/pricing. Don't try to work around it.

## Updating

Commit or stash local changes first (or copy the files), so the update can be undone. Read https://notchset.dev/r/changelog.json for the new versions: a major version or a merge says what to change. Then re-run the install with `--overwrite`, on a branch. It replaces the component's files, the shared helper files they import, and the item's CSS rules in the global stylesheet, so review the whole diff (components, shared files, CSS), re-apply your own edits, and run the app's typecheck, tests and build.
